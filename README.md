# Mohamed Ibrahim — Developer Portfolio

Personal portfolio of Mohamed Ibrahim: Computer Science student (Arab Open University), web and AI developer based in Cairo.

Live site: https://mohamed-ibrahim-hamdi.github.io/

## Stack

- React + TypeScript, built with Vite (single-file build: `index.html` is fully self-contained)
- Hand-written WebGL 3D hero scene (no libraries): rotating icosahedron, orbit rings, pointer/scroll-reactive star field
- Bilingual Arabic/English toggle, mobile-first, reduced-motion friendly
